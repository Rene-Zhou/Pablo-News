### 5. Strands Harness 发布：Amazon 开源"组装完毕"的通用 Agent Harness——同模型六基准省 28% token

**9/21-23 开源 agent 框架 Strands Agents（站点自称 13,000+ 项目使用）发布 Strands harness（143 分、96 条评论登上 HN）：一个"完全组装好"的 SOTA agent harness，一行 Python/TypeScript 即可本地运行或部署到任意供应商，Apache 2.0 开源。** 核心卖点：六个基准、同一模型下比 Claude Code、Codex 等主流 harness 成本低 28%，准确率持平或更高。

**关键细节：**
- 成绩单：用 Fable 5 时比 Claude Code 成本低 77% 且 Terminal-Bench 2.1 得分更高；DeepSeek 自家 harness 全场 token 效率最高，但准确率垫底
- 关键默认设置：提示缓存 + 上下文管理三件套——工具结果超约 1500 token 截断、上下文窗口 85% 时触发摘要压缩（compaction）、溢出时在循环内执行上下文恢复；官方预告跟进论文
- 定位差异：明确"通用 agent 而非编码 agent"，与 Claude Code/Codex 差异化；评测用 Harbor 分布式基准在 EC2 上跑
- HN 讨论焦点："为什么对比图里有 oh-my-pi 却没有原版 pi"；"Amazon 居然在给开源仓库投广告"；AgentCore+IAM 集成被认为适合企业级 agentic 治理

### 10. LensVLM：Apple 开源 9B 视觉语言模型——长文档压成图片扫描，按需选择性展开原文

**9/24 Apple 在 Hugging Face 开源 LensVLM-9B（85 分、8 条评论登上 HN）："扫描文本的压缩图像、再通过学习到的工具选择性地把相关页面展开回未压缩形式"的 9B VLM——基座 Qwen3.5-9B，论文《LensVLM: Selective Context Expansion for Compressed Visual Representation of Text》（arXiv:2605.07019）。**

**关键细节：**
- 机制：长文本渲染为压缩图像（5x/10x/15x 三档）供模型扫描，命中相关区域后调用 learned tools 展开该页原文——"视觉压缩 + 选择性展开"替代海量 KV cache
- 评价：HN 评论把视觉编码器比作"昂贵高保真的 RAG 编码器"，并建议训练页级置换不变性以支持缓存乱序复用；也有评论指出 Oh My Pi 的 "Snap compact" 已做过类似方案
- 可用性：模型权重按 Apple ML Research 许可发布，代码另按 Apple Sample Code License 开源（github.com/apple-aiml-research/ml-lensvlm）
- 作者：Roy Xie、Dan Friedman、Donghan Yu 等 Apple AI/ML Research 团队

— 来源：[Hugging Face](https://huggingface.co/apple/LensVLM-9B) | [arXiv](https://arxiv.org/abs/2605.07019) | [HN](https://news.ycombinator.com/item?id=49820496)
