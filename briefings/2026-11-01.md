### 1. 🔥 Anthropic 把 Claude 变成了 Linux 内核零点击 RCE 的"猎手"——研究博文《Discovering and exploiting vulnerabilities in critical, real-world software with Claude》披露：其内部模型对 Linux IPv4 TCP 握手路径给出 CVSS 9.8 的 UAF（CVE-2026-98432），PoC"无需凭证无需交互"在带 MPTCP 监听的服务器上 root 执行命令——而 Ubuntu/RHEL 至今未出补丁（Anthropic 博文 10/27；CVE 披露文 10/29；HN 87 分且仍在涨）

**Anthropic 前沿团队博文（10/27）分七章展示 Claude 在真实关键软件中"发现并利用"漏洞的全程：Chrome 一键 RCE、Safari 一键利用链、Android 锁屏绕过、Windows 远程拒绝服务、以及本章主角——Linux 零点击 RCE。CVE-2026-98432 是 IPv4 TCP 握手路径上的释放后使用：内核把保存的选项从请求 socket 交给新连接时未加拷贝、连接一走就释放，而另一颗 CPU 还在读它构造握手应答——远程未认证对端即可触达。漏洞由 Linux 内核 CNA 评 CVSS 3.1 9.8（Critical）；Anthropic 称 PoC 由 Claude 在初步提示后自行写出，"在带 multipath TCP 监听器的 Linux 服务器上以 root 执行任意命令"，其复现中"泄漏一个内核指针耗时 48 分钟、再 5 分钟拿到 shell 命令执行"。**

**关键细节：**
- 修复状态的不对称是最大看点：上游稳定版 10/11–10/15 已出四行修复（5.10.272 / 5.15.223 / 6.1.190 / 6.6.159 / 6.12.113 / 6.18.56 / 7.2.10 / 7.3，bug 可追溯到 Linux 4.4），Debian 与 SUSE 企业内核已有补丁；但截至 10/29 晚，Ubuntu 追踪器全线仍标 "Vulnerable"、RHEL 8/9/10 列为受影响无修复——"多数服务器跑的是发行版内核"正是风险敞口所在
- 利用门槛的社区对账：peanut-walrus 梳理——非 MPTCP 场景下是通用 UAF、非 MPTCP 所必需；多数 ISP 路由器丢弃带 IP options 的包，公网直接利用受限；Red Hat 称自行丢 ipoptions 有帮助但非完整缓解；成功利用需多核处理分包，单核或分包钉在单核的系统不受影响
- 触达面：应用须显式开启 MPTCP socket——但 Go 1.24 默认开启，Caddy 跟随；HN 读者实测发现 Tailscale 也在开 MPTCP 监听；wahern 补充 MPTCP 的最大用户是 Apple/iPhone，其普遍性正是 Linux 服务端跟进实现的动因
- 连续性：与本周"密钥与签名基础设施"三部曲（Binance、Cursor 市场、Northflank，10-31 第 1、2、4 条）同读——本周讲"守方被打穿"，本条讲"攻方产能已被 AI 化"；与本报"验证成为瓶颈"线（Hex、Thoughtworks、Simantic）互为反面：当生成侧是攻击者，验证侧（补丁分发）就成了防御的瓶颈

### 2. 🔥 Parameter Labs：一条公开分享链接即可接管任何 ChatGPT 账户——MathLive 的 postMessage 监听器 origin 策略为 none，沙箱里的 HTML Preview 借"邮件槽"把恶意布局送进主页面，再用 YouTube oEmbed 的 JSONP 错误响应绕过 CSP，srcdoc iframe 拿到 chatgpt.com 身份执行任意 JS；OpenAI 定级 P1、10/26 修复，赏金合计 5,000 美元——HN 全楼一致认为"这价钱是个笑话"（HN 281 分、130 条评论）

**Parameter Labs（安全研究方，Mukul Goyal，10/28 发布）：攻击链由两个各自无害的特性拼成——一个函数图像（graph）与一个 HTML Preview。graph 会让主页面加载公式渲染库 MathLive 并注册消息监听器；沙箱化的 Preview 与主页面不同源、互相读不了对方的页面，但"邮件槽"仍在：MathLive 顶层的 origin 策略却是 none——接受来自任意网址的 postMessage，且不要求 update-setting 消息来自先前批准过的窗口。Preview 于是发两条消息：第一条用攻击者的 HTML 替换虚拟键盘布局，第二条叫出键盘——MathLive 把布局拼成 HTML 字符串塞进主页面 innerHTML（名为 createHTML 的助手看似消毒实则放行）。script 标签经 innerHTML 不会自动执行，下一步是无 sandbox 属性的 srcdoc iframe：新文档里外部脚本能跑，且因为框架由主页面创建，浏览器给它 chatgpt.com 身份、可访问父页面。最后一关是 CSP——ChatGPT 的策略正确拦了内联 JS，但放行了 YouTube：YouTube oEmbed 端点先把 callback 塞进响应再返回校验错误，`callback=globalThis.__marker=31337;void` 即让 YouTube 域下执行任意代码。**

**关键细节：**
- 从实验室到真实攻击的收口最见功力：早期版本需要受害者先连接研究者的 App；最终载体把两件套直接放进一个普通公开对话——一个真 graph 初始化 MathLive、一段助手生成的 HTML Preview 发消息，导出为公开 /share/<id> 链接后整条链保留；受害者无需装 App、进 Project、贴代码或开开发者工具，最稳路径也只需点一次 Preview 按钮，后经标记 previewable 做到"打开链接即中"（独立账号三次复现、硬刷新后仍中，约 4.5 秒出弹窗）
- 实测能力：枚举受害者会话列表、读取从未分享给攻击者的私聊内容、外传数据、直接以受害者身份调用 ChatGPT 已认证 API——"本质上接管账户"
- 赏金争议是评论区主旋律：yellow_lead "还是得点链接，但这赏金太低了，别人可能就不报了"；hridyaagrawal 与 Kuyawa 直言 "$5000 对 P1 是个笑话"；Kuyawa 的情绪化长评被顶："高薪养着审计公司，真给你看平台大洞的人只配拍拍肩膀？"
- lxgr 的关联被顶起：叠加此前"ChatGPT 桌面版 Work 聊天可远程访问文件系统"（HN#50078284），ChatGPT 客户端攻击面正在变大；joshuamoyers 则吐槽 Parameter 的"代理蜂群随机破门再借披露做营销"——测试环境披露也引发是否越界的讨论
- 连续性：本周凭证链被打穿的三部曲之后，本轮轮到"会话层"——攻击面从基础设施（热钱包签名、市场发布通道、环境变量库）上移到 AI 应用自身的沙箱模型；与昨日 Claude Code 扩展后门（10-31 第 2 条）同读：AI 平台的"分发与渲染层"正在成为新的主战场

### 3. 🔥 Talos 拆解 VOLTA"自动_doxxing_窃密器"：偷完凭证把"证据包"喂给 LLM 当情报分析师——系统提示词要求输出《WHAT THEY'RE WORTH》（按变现价值低/中/高给资产排序）与《THEIR OPSEC》（评估受害者的安全卫生）；默认模型 Claude Opus 4.6，被拒就级联切换 Kimi K2 → Gemini 2.5 Flash——"预期会撞上模型护栏"本身被写进了架构（HN 208 分、113 条评论）

**Cisco Talos《Appraisal by AI》（10/31，Ryan Fetterman）：新恶意软件自称 VOLTA-AUTODOXER，经 CAIRN 研究项目浮出水面——成熟 Windows 窃密器植入 + 可选 AI 集成层。一次遍历即窃取 Chromium 系浏览器凭证/Cookie/保存的支付卡、Firefox/Thunderbird、Outlook 配置、Slack 工作区、Steam 与 Battle.net 会话、Discord token、Telegram 会话、Roblox 账户、SSH 与云厂商配置文件（gcloud、OpenVPN、Hide.me）；不只拷贝加密钱包，还在本机内嵌破解器现场破解金库、把结果写进自己报告行的"WALLET VAULTS CRACKED"；WlanGetProfileList 直接调用，把每张保存过的 Wi-Fi 密码拖成明文。真正把它与商品级窃密器分开的是收集之后的事：一轮"活体富化"——用偷来的 Gmail token 查收件箱里 Amazon/DoorDash/Uber Eats/Grubhub/Walmart/PayPal 的收据以确认家庭住址，直调 Uber Eats/DoorDash 会话拉外卖历史，用 Discord token 富化账户资料，Rolimons 实时估 Roblox 库存价值。全部打包成 Identity_Report.txt，以 JSON 序列化 POST 给 OpenRouter，系统提示词令其扮演"起草目标评估的法医情报分析师"。**

**关键细节：**

- Talos 的定调句："网罗一切、全部偷走、让 AI 来分拣"是网络犯罪的新思想——AI 集成的新闻点不在支撑传统恶意能力，而在"代表操作员当情报分析师"；HN：markstos 把它推向下一站——"排好序后，受害者可按价值配给攻击预算：高价值目标才配得上零日与深度伪造这类昂贵弹药"

## 模型与基础设施

### 6. skeeto 开源 Prospero：反 web 栈的本地编码 harness——C++ + Dear ImGui、5MB、"比其他 harness 少两个数量级的资源占用"；设计第一原则"永不无限等待"：每个操作都有 deadline，权限请求超时即拒绝、agent 必须学会没有也要活；自带 vision 桌面控制、可远程部署 headless 引擎、能驱动 fuzz 战役并在发现 bug 后现场修复继续跑（HN 168 分、111 条评论）

**nullprogram（Christopher Wellons，10/31）：动机直白——"我关注本地 LLM 两年了，够好的开放权重模型已经能处理较简单的编程任务，这需要一个编码 harness，但今年至今所有 harness 都让我失望。出于无法解释的原因，多数用 web 栈构建、吃掉海量内存。归根结底 harness 就是 curl 粘上 popen()，不该需要 GB 级的 RAM。"不内置任何模型供应商：llama.cpp、公司内网模型、OpenRouter、Anthropic/OpenAI API 皆可（但不能用 Claude 订阅——评论区补充：$100/$200 档订阅含 API 额度）；配置用 INI 而非 JSON，支持远程 include（含 URL）但硬性禁止出现在 shell 命令里的任何东西。**

**关键细节：**
- "永不无限等待"落实为产品哲学：所有网络请求有超时、watchdog 防无限等待、agent 邮箱有界、超时 shell 命令自动转后台异步并定期唤醒 agent 决定是否继续——唯一例外是 Plan 模式（ask_user 后无限等待，因为那时用户理应在场）；"被动渲染 + settle 帧"：没事可做时什么都不做，agent 等构建期间不啃 GPU
- 杀手级场景是 fuzz：因为足够精瘦，"它可能是唯一能驱动 fuzz 战役的 harness——不会让 Linux OOM killer 先杀掉吃内存的 harness 而不是失控的 fuzz 目标"；"为什么要让 agent 跑 fuzz？因为它能在发现 bug 后当场修复、让战役继续——想都不用想"
