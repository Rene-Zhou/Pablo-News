### 2. Debian 紧急修复 apt 包管理器的中间人任意代码执行漏洞——更新通道自身失守，安全公告发布即"用带漏洞的更新机制去修漏洞"悖论；评论区最快止血方案：`Acquire::Retries=0`（HN 120 分）

Debian 安全公告 DSA（lists.debian.org msg00526，11/4）：apt 包管理器存在中间人攻击路径下的任意代码执行漏洞，官方已发布安全更新。这条新闻的自指结构让它比普通 CVE 更棘手——HN 评论区 8organicbits 点破悖论："既然更新机制本身有漏洞，他们应该附上手动更新说明"；他同时注意到自己的系统已经通过 unattended-upgrades 自动装上了补丁，并转引 lobste.rs 上的建议用 `apt download` 手动获取。xeyownt 给出更轻的缓解："CVE 要求非零重试次数才能触发——把 `Acquire::Retries=0` 设为零可完全绕开（除非你的包已被改过）。"另有一位用户标注该讨论是两小时前另一帖（HN#50364814）的重复提交。

**关键细节：**
- 中间人 + 重试机制的组合意味着攻击面主要在不可信网络路径上的镜像/代理场景，但对批量自托管服务器而言仍是"更新即入侵"级别的通道风险

### 5. Nvidia RTX Spark 笔记本被曝"加密固件把 Linux 推理锁到 35% 速度"——插电即把 GPU 时钟锁死约 780MHz（Windows 约 2.2GHz），GPT-OSS-120B 实测从 65.4 tps 掉到 13.9；根因是"平台控制器与框架"组件的功耗表只有 Windows 驱动能解密，Linux 无等价物（HN 531 分、242 条评论）

MindStudio 的实测长文（11/1）：Linux 在 RTX Spark 笔记本（测试机 MSI Prestige N16 Flip AI Plus）上可以完整安装运行，开源内核驱动、4K/120Hz 输出、键鼠触控板皆可点亮——但插上电源后 GPU 时钟即被锁在约 780MHz。基准差距：GPT-OSS-120B 上 Windows 65.4 tokens/s、WSL 65.1、DGX Spark 台式机 61，而同机原生 Linux 只有 13.9。根因是一个 Windows 专属组件"Nvidia Platform Controllers and Framework"：它管理 CPU/GPU 间电力分配，其功耗表被加密、仅 Windows 驱动可解密。另一处坑：96GB 统一内存默认几乎全部分给 GPU，而调整内存切分的设置只有 Windows 暴露。作者的结论是"今天 WSL 才是务实的中间道路"。标题本身也经历了一次纠错：原题写 DGX Spark，评论区指出 DGX 默认就是 Linux 系统、问题只存在于 RTX Spark 笔记本，提交者随即改题。

### 6. Anthropic 公布"可证明推理"研究进展 FlashProve：zkSNARK 让模型服务商能密码学地证明"这条回复确实出自这个模型"——Llama 4 Maverick（400B MoE）单张 H100 以约 110 tokens/s 生成证明、每 1024 token 请求约 19MB，比此前开源系统快几个数量级；文中直书"是 Claude 找到了新的方法"（HN 129 分、59 条评论）

Anthropic 11/2 发布研究博文《Progress on provable inference for large language models》（作者阵容横跨 Anthropic Frontier Red Team、EPFL/StarkWare 的 zkSNARK 宗师 Alessandro Chiesa、MIT 的 Miranda Christ 等）：用户今天无法验证回复真的来自厂商声称的那个模型——而非被路由服务为省钱偷换成降级模型、或被攻击者篡改的 token 流。zkSNARK 证明可解此题：提供商对模型做承诺（commit），再为每条回复生成"确由该模型产出"的零知识证明。数字面：对 400B 参数 MoE 的 Llama 4 Maverick，单张 H100 以约 110 tokens/s 生成证明，4-bit 量化权重 + prefill 整数算术下每 1024 token 请求证明约 19MB，开销约为 vLLM 跑模型本身 GPU 时间的 70-95 倍——而此前的开源系统"慢几个数量级"。博文的措辞值得注意："Claude found novel ways to apply…"——改进本身即由 Claude 产出。

Tom's Hardware 报道：美国中期选举日，45 项与数据中心开发相关的措施被放上选票，结果是对开发的"全面否决"（comprehensively defeated）——选民对 AI 数据中心侵扰社区的态度首次以批量公投的形式留下记录。HN 讨论迅速给出三层修正：地域例外（"佛罗里达还是选出了亲数据中心州长"——回应是"佛州是压倒性拒绝中唯一的孤立离群点"）；结构延续（tocs3"数据中心开发并未就此终结……监管俘获仍在牌桌上，在建项目仍在建"）；以及外溢效应的具象样本——一位医院系统工程师留言："我们在装一台 MR 扫描仪，冷水机组开始缺货、交期漫长——供应商说数据中心想要的型号短缺，他们只好抢购替代型号"（AI 建设潮对非科技行业供应链的挤压已到医疗设备层）。"也许我们在这十年结束前又能买得起电脑了"则拿 GPU 价格开涮。
