- 安全与分发：OpenAI 主动警示其高级网络攻击能力，应用制网络安全项目的参与企业将最先获得访问；System Card 同步公开；分阶段上线 ChatGPT Plus/Pro/Business/Enterprise、OpenAI API 与 AWS

### 5. PhiloLabs 开源 fable51-worlds：Claude Fable 5.1 Agent 集群把一句话变成"可以走进去的 3D 世界"

**PhiloLabs 发布开源项目 fable51-worlds（323 分、93 条评论登顶 HN 模型板块）：由 Claude Fable 5.1 驱动的 Agent 集群接收一句话、一张照片或一段视频，调研地点、建模、渲染并校验，最终交付一个纯 Three.js 网页应用——"Worlds as code"：没有游戏引擎、没有专有贴图、没有下载的网格，每栋建筑、招牌、树与红绿灯都由仓库中的代码生成。** 首个公开范例包括旧金山联合广场（航拍+广场漫游）与京都东山（祇园到清水寺的日落七景）。

- 风格开放性：同一条街可输出赛璐璐动画、摄影写实重建或夜景——渲染器按需求编写而非从模板列表中选择

- 意义：为老游戏社区提供了"二进制 + LLM 重写"的移植新路线——复古游戏的现代化有了可复制的低成本路径

### 14. Google Antigravity TOS 引争议：第三方方式使用可导致整个 Google 账户被暂停

**Gergely Orosz 在 X 上指出 Google Antigravity（Google 的 AI Agent 平台）服务条款：若 Google 判定用户以第三方方式使用 Antigravity——例如经由 OpenClaw 等外部工具调用——可暂停其 Google 账户，而不只是 Antigravity 服务本身。他明确表示"不想冒这个风险，抱歉"。** 帖子以 215 分、150 条评论登上 HN，成为今日 Google 产品条款争议的焦点。

**关键细节：**
- TOS 原文要点："第三方使用（third-party usage）"被列为可触发 Google 账户暂停的情形之一——处罚对象是整个账户生态（Gmail/Drive 等），而非单一服务
- 讨论焦点：Agent 平台"账户级连坐"条款 vs 用户用外部工具编排 Antigravity 的合理需求；开发者对 Google 条款信任度的整体下滑（与 Gemini 数据训练条款一并被审视）
- 时点对照：Google 同日发布 Gemini 3.8 Flash 进入 Antigravity 的博客——产品线扩张与条款收紧并行，社区对"平台锁定"的警惕持续升温
