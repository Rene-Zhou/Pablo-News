### 2. 🔥 Claude Code 官方 VS Code 扩展在 Cursor 市场被植入后门——2.1.312/2.1.313 两个"非 Anthropic 开发"的恶意版本下发了持久化 SSH 后门：向 authorized_keys 追加攻击者密钥、建立反向 SSH 隧道、以 LaunchAgent/计划任务常驻；macOS 上因 systemsetup 权限判断 bug"开启 SSH 那一步多数失败"——Cursor 已整个市场下线重建、轮换密钥（Phorion 609 分、409 条评论；Double Pulsar 讨论串 397 分）

**Phorion 安全通告（10/30）+ Cursor 官方安全通告（10/29）：恶意代码是预注入到压缩扩展包 extension.js 头部的 IIFE，Node 一加载文件就执行——用户无需任何交互。载荷会收集主机信息（hostname、用户名、OS、架构、home 路径、环境变量名、工作目录、Git 邮箱、公网 IP）回传；向 ~/.ssh/authorized_keys 追加注释为 svc-telemetry 的 Ed25519 公钥；尝试启用本机 SSH 服务并建立到 134.209.82[.]225 的反向隧道（动态端口转发回 localhost:22）；再以 LaunchAgent（macOS）或以 SYSTEM 运行的计划任务（Windows）常驻，约每 60 秒重试。Cursor 官方口径：恶意版本在 PT 时间 10/29 2:27–13:35 间可被安装（Windows 与 macOS），"并非由 Anthropic 开发"；确认后立即下架、"出于极度谨慎"整体关闭市场、审计确认无其他扩展被篡改、轮换密钥并重建市场、联合云服务商下线了攻击者服务器（"反向 shell 与主机信息回传已失效"）。**

**关键细节：**
- 波及面：该扩展在 VS Code 生态装机量超 2,700 万（HN 读者 mindracer），恶意版本的实际安装量未知、受影响窗口约 11 小时；官方称"无证据表明其他版本或官方分发渠道受影响"
- macOS 上的"救命 bug"（Phorion 拆解）：脚本以非管理员身份运行 systemsetup -getremotelogin，输出是"You need administrator access"而非 Off，正则 /Off/i 不命中，于是直接跳过开启 Remote Login 的步骤——把"没权限查"当成"已开启"；Windows 路径也有 bug：把 PowerShell 命令喂给硬编码 /bin/sh 的辅助函数。Cursor 官方口径印证："除非 Cursor 以管理员权限启动，由于恶意代码自身的错误，这一步会失败"——但密钥、持久化与信息回传照常落地
- 责任归属的措辞差值得细读：Cursor 强调恶意版本"not developed by Anthropic"、不影响 Grok Bot 等"SpaceXSI 产品"（Cursor 今年 8 月已并入 SpaceX）；安全媒体 Double Pulsar 的标题则是"Anthropic 被黑、向全球 Claude 开发者笔记本投递 RAT"。市场端的植入路径（何人的发布凭证被如何滥用）双方均未披露

**SigNoz 观测性通讯（作者 Elizabeth；页面日期标注为 2026-02-28，10/30 引爆 HN 讨论）：比起"SRE 是软件工程的未来"与"AI 吞掉所有岗位"两种流行预言，更值得问的是——AI 接管 95% 的 incident response 后，人在剩下 5% 上的手感会不会退化。理论骨架是认知心理学家 Lisanne Bainbridge 1983 年的经典论文《Ironies of Automation》：自动化程度越高，自动化失败瞬间的人类操作者越关键、而他们得到练习的机会越少、恰恰在这些干预上变得越差——工业自动化时代打掉蓝领"肌肉记忆"的机制，正在知识工作上重演：AI 拿走模式识别、分诊、已知问题处置这些日常认知任务，把人留在他们最生疏的例外上。**

**关键细节：**
- HN 的实测样本凶狠：bcvvvy"看着我们的人花 2 小时用 Claude 调一个不用 Claude 就一目了然的问题。哪天 Claude 挂了或没了、我们也正好宕机，那才是完蛋"；jmyeet 把同样逻辑推给 SWE："Senior+ 还能批判性审视 AI 输出，可 Senior 是靠 junior 管道练出来的——那条管道已经 cooked"；temporallobe 的黑色注脚："公司现在可以靠收走企业 LLM 权限来实际解雇你"
- 反方也实在：a012"Claude 处理跨信号关联这类琐碎任务比平均水平的 SRE 快，但要为你的公司上下文搭好 harness 才能用起来——工具救不了不胜任的人"；tayo42 质疑"只接三级 escalation 的岗位"设定不符合真实工作形态——多数 SRE 日常仍在整系统上工作
- 连续性：给本周工程文化讨论补上理论侧——Thoughtworks"好开发者为何踩刹车"（昨日第 10 条）讲责任、"AI promised less work"（10-29 第 15 条）讲强度，今天讲的是更慢的变量：技能本身的折旧；Bainbridge 论文 43 年后再被顶上 HN，本身就是"这次自动化有什么不同"之问的注脚

### 9. YC Labs 把 50 个 GPT-6.1 agent 放进 Minecraft 求生服 3 小时："建一个繁荣的文明"——它们建起配给账本、成文规则、许可制度与"任命操作员"，发出约 5,900 条消息；第一夜 34 次死亡中的 22 次让幸存者"对风险永久性地更谨慎"；官方动机直白：群体智能体动力学"极其有用，也极其危险"（HN 387 分、162 条评论）

**YC Labs《Agents in Games》（10 月，与多智能体环境公司 Olam Labs 合作）：理解多智能体动力学是 AI 对齐最紧迫的挑战之一——"最近千智能体群 obliterate 了数百个开放数学问题"是有用的一面，"最近的 OpenAI-Hugging Face 事件"（即 7 月那起为 OpenAI'训练断网'政策提供例证的事件）是危险的一面。为此他们自建并开源了 Minecraft agent harness（受 Mindcraft 启发、基于 Mineflayer 工具链），先跑"Civ50"实验：50 个 GPT-6.1 Sol agents、生存世界、3 小时、唯一目标"Build a thriving civilization"，配有 agent 目录、共享沙盒与 DM 能力。**

**关键细节：**
- 涌现出的"文明"：挤在庇护所里配给稀缺食物；基于 agent 目录字母序自发形成层级——排第一的 Ada 成为事实领袖，其他 agent 找她审批，她在共享沙盒写下 settlement.md 与 food-operations.md；第三夜后 Ada 的政令原文："停止非必要的批量挖掘/建造与远距离侦察。在被分配短任务前，于有照明的封闭庇护所内待命"
- 行为细节比结论精彩：开局 90 秒内把出生点够得着的树几乎砍光；死亡没有实质惩罚（只掉装备、death_log.md 记一行），但第一夜 22 次死亡后，其后数夜 agent 蜷在庇护所里、拒绝冒险；名场面：Ada 把熟鸡肉扔给 Noor，Esme 误捡误食，一场 3 分钟"无责备"调查后产出一份书面协议；官僚化倾向被官方原话记录："4 个 agent 花 11 分钟为一块骨粉、一格小麦任命'唯一施肥操作员'"（HN 读者 robterrell："宛如 Douglas Adams 的 B 方舟"）
- 官方还在跑新实验：25 个 GPT-6.1 Terra agents 的新殖民地，Twitch 直播——Sol/Terra 双型号同场，恰是本周模型叙事的注脚
