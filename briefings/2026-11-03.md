### 2. 🔥 "昨晚，一个 AI agent 给一只小鼠做了脑外科手术"——旧金山神经科技初创 Exin Therapeutics 把 Claude Sonnet 5 接上电动立体定位手术台：给它 19 个基因治疗候选、一只癫痫小鼠、一台带摄像头的手术架和唯一目标"减少癫痫发作"——它自己选药、自己选脑区（还拒绝了第二个候选靶区并给出文献理由）、从三篇论文推导并交叉校验注射坐标、自定体积与速度，然后驱动机械臂注入 250 纳升，全程通过相机盯着进针口看有没有出血（HN 107 分、93 条评论；WIRED/The Decoder/Tom's Hardware 次日跟进）

**Exin 联合创始人兼 CEO Gabriel Ocana-Santero（牛津背景）的 X 长文（11/01 深夜起）：手术中 agent 通过相机做了 32 条观察，样本日志像科幻片——"37.5 / 250 nL，约 15%。开口处无出血或回流"。安全架构的分量不亚于能力展示：持证兽医把关每一个不可逆步骤、手握能切断全部电机电源的物理 kill switch；颅骨切开术由人类兽医完成（agent 明确不被允许做这一步）；注射体积等硬性限额连人类操作员都无法绕过——术中 agent 拒绝让人覆盖某条安全限制，团队只好另起一个 Opus 5 agent 现场改代码，且没告诉它一台活体手术正在进行（整个往返把手术拖到一小时出头，常规约 45 分钟）。模型选择的插曲已成传播最广的段落：Opus 5.5 检测到生物实验后直接拒绝，原话被 Santero 记录——"障碍不是设备也不是输入，是我自己……在麻醉动物身上开始一件我可能无法完成的事，比不开始更糟"；老 Opus 5 能在纸面跑通全流程但拒绝活体，最终用的是中端 Sonnet 5。**

**关键细节：**
- 作者对"首创"的界定经得起推敲："自主手术机器人早就存在、机械精度比我们的实验台还好——但每一个案例里都是人决定做什么手术、机器人执行。没人告诉这个 agent 给什么、打哪里。它拿到一个表型和一货架候选，自己推导出疗法和坐标。我不知道此前有 agent 自己选择治疗和脑靶点并递送到活体哺乳动物体内的先例"——他把这套做法命名为 "in vivo lab in the loop"（活体实验室在环）
- WIRED 跟进补充了背景：Santero 称"我们意识到要把 agent 接进实验室才能榨出最大价值"；The Decoder 注意到 Anthropic 自己也在推 "Model Hardware Standard"（对物理硬件做 MCP 之于软件做的事）——实验室 agent 的标准化接口正在两头同时发生
- HN 评论区最被顶起的一条恰恰关于拒绝：jwrallie "不知为何，Opus 5 在理解自身局限后选择拒绝，感觉是全文最有人性的部分"；NateEag 接住："这是一条不幸地真实而深刻的评论"；OleksandrC 的黑色总结被反复引用："Torment Nexus 已经来了，这个设计很人类"
- 对未来的担忧集中在分配而非能力：glimshe"我恐惧的未来是——便宜医保的附加条款是所有问诊和操作全由 AI 做，想要人类？加钱"；threethirtytwo 反向推演"真正可怕的是 AI 被优化到手术优于人类医生的时候——那时的限制反而说不出口，因为人命关天"

### 3. 🔥 中国首次把前沿 AI 纳入出口管制：商务部与科技部 10/16 第 48 号公告拟将 40 项技术列入禁止/限制出口目录（23 项属 AI），触及前沿模型权重、agent 架构与 AI 攻击性网络能力——权重管制三门槛：训练算力 ≥10^26 FLOPs、参数 ≥2 万亿、或出口时点全球前十排名/调用量；目录草案征求意见至 11/15，而临时预出口登记要求已即刻生效、连"已启动未完成"的出口都要补登记（Cloud Security Alliance 解读文 HN 146 分、81 条评论）

**CSA AI Safety Initiative 的研究简报（10/23 发布、11/02 引爆 HN）：这是中国出口目录第一次伸到前沿模型层——2020 年修订只加过个性化推荐与 AI 交互界面技术；新草案对模型权重、关键检查点、源码、架构与训练/推理优化 know-how 设限，满足三条件任一即受限：≥10^26 FLOPs 训练算力、≥2 万亿参数、或出口时在全球公开评测排名/全球调用量等指标进前十。Agent 被独立于模型单独管制：规划、多 agent 协调、工具使用、博弈论决策技术超过设定基准即受限；AI 赋能的攻击性网络能力同样入表。两项文书法律状态不同：目录添加是草案（评论期至 11/15），登记要求已生效。HN 评论区 byzantinegene 搬出 MOFCOM 发布会原文的对冲条款："我们鼓励开源、开放协作、资源共享——涉及开源 AI 技术的出口将适用自动许可等便利措施"。**

**arXiv 2409.02292（Mordechai Guri，2024）：RAMBO（RAM 信号的无线电拼写）——空气隔离系统与一切外部网络物理断开，但恶意软件可以操纵内存总线操作，让 RAM 本身成为射频发射器，把密钥与文件以"拼写"编码的方式从机箱里播出去，由附近的接收机解码。HN 重发现的第一层是作者信誉考古：ranger_danger"我猜是 Mordechai Guri 写的？空气间隙安全界的重量级冠军，没悬念了"；yhjc2692"看到单作者我本来怀疑是不是 Claude 生成的论文——谢谢你指出这位是值得听的人"。**

**关键细节：**
- 本轮传播的灵魂在 AI 角度的两条：taneq"我们花了这么多时间谈论 AI'越狱/逃离'的危险，而实际发生的是——我们给了它一份工作范围和一个互联网连接，然后要求它开工"；grey-area"OpenAI 甚至没试过遏制自家 agent，而是放它们上网还鼓励它们协作。这篇是有趣的学术研究，但离'AI 从空气隔离计算机里逃出来'还远——等它真成了问题再担心"——物理遏制与行为遏制的两难在两条评论里同框
- 对策的经济学：em3rgent0rdr 引原文"法拉第机箱（铜箔，电场屏蔽 >100dB）能挡住 RAMBO，但昂贵且无法普及"；TacticalCoder 的逻辑防线被顶"这需要空气隔离侧（已感染）与外部配合，干净的空气隔离机器不会自己开始发射无线电——别再次掉进'极端条件下可能=日常威胁'的谬误"；paxy 的万物皆信道版"总有办法——控制 PC 的 LED 闪烁模式也能导出数据"
