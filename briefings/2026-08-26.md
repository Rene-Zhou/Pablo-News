### 10. Headlong：永不停机的"常驻 Agent"微框架——Laude × MIT 合作，核心不到一万行 Bash

**Laude 与 MIT 合作发布开源项目 Headlong：一个主打"持续自主性"（persistent agency）的 Agent 微框架——Agent 永远不会入睡，在没有外部输入时也持续自我思考，外部消息只是注入其思维流的"一条观察"。** 以 114 分登上 HN。

**关键细节：**
- 与主流框架的差异：reactive harness（任务完成即冻结）和 cron/心跳唤醒模式都不需要了——"没有清单，除非 Agent 自己创建清单"；核心实现不到 1 万行 Bash，一行命令安装
- 团队实践：Laude 让团队成员共享同一个 Agent "Audel"（Slack/Telegram/移动端），它会主动 ping 成员汇报自己发起的新项目，接续不同成员的话题
- 警告：alpha 研究软件，Agent 会执行 shell 命令——必须沙箱运行、使用限额 API key（"你的 Agent 全天候思考"），不要共享敏感信息
