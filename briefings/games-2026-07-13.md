### 1. 🔥 HLE 3-2 击败 BLG 夺得《英雄联盟》MSI 冠军，LCK 第五冠

北京时间今日凌晨，2026《英雄联盟》季中冠军赛（MSI）总决赛落下帷幕。LCK 一号种子 HLE 与 LPL 二号种子 BLG 鏖战五局，最终 HLE 以 3-2 击败 BLG 成功夺冠。这是 MSI 采用双败淘汰制以来，首支从败者组一路杀出并最终捧杯的队伍，也是 LCK 赛区第五座 MSI 冠军奖杯。

- 本届 MSI 连续爆冷：TES 1:3 不敌越南 TSW、G2 淘汰 T1、G2 又被北美 3:0 横扫，四大赛区格局剧烈震荡，最终仍回归中韩对决经典剧本

### 2. 🔥 黑曜石确认开发《辐射》新作：《新维加斯》原班人马回归，延续第一/三人称开放世界

彭博社与知名爆料人 Jez Corden 先后证实，黑曜石娱乐在经历 25% 裁员和取消《宣誓》续作后，已全力转向《辐射》系列新作开发。设计总监 Josh Sawyer——2010 年《辐射：新维加斯》的主创——将再度执掌该 IP。这是继 Xbox 大裁员风暴中为数不多的积极信号。

关键细节：
- 据彭博社报道，贝塞斯达将与黑曜石联手开发该项目，Josh Sawyer 此前负责的一款类《辐射》新 IP 也被整合进该项目
- Jez Corden 爆料称，新作不会回归初代俯视角，延续第一/三人称自由切换的现代开放世界框架
- 《宣誓》续作因不符合 Xbox 负责人 Asha Sharma 的"聚焦最强 IP"战略而取消，部分员工将借等待期继续推进续作以保留复活可能
- 黑曜石同时将继续《天外世界2》DLC 和《禁闭求生2》的开发
- 过去二十年中唯一非贝塞斯达开发的《辐射》正是 2010 年的《新维加斯》，粉丝期待黑曜石再度复刻其剧本深度

— 来源：[机核](https://www.gcores.com/articles/216927) | [游民星空](https://www.gamersky.com/news/202607/2170289.shtml)


### 3. 🔥 id Software 裁撤近半数员工，3D Realms 联合创始人称其「名存实亡」

据 Game Developer 报道，老牌 FPS 开发商 id Software 在 Xbox 最新一轮大裁员中遭受重创：裁撤约 95 名员工，占团队总规模的一半。裁员集中在程序员、QA 和工具开发等技术岗位，多位入职超过 10 年的资深开发人员被解雇。

关键细节：
- 3D Realms 联合创始人 George Broussard 表示，id Software 核心团队仅剩管理层、美术和设计人员，"作为开发工作室已名存实亡"
- 自主研发的 id Tech 引擎前景堪忧，分析认为可能被放弃转而采用虚幻引擎，与 CD Projekt Red 和 Halo Studios 转型路径相似
- 《毁灭战士：黑暗时代 启示录》可能是工作室未来很长一段时间的最后一个项目
- 尽管 Xbox 计划继续投资《毁灭战士》和《雷神之锤》IP，但几乎所有技术骨干的离职让开发前景极不明朗
- 此轮裁员紧随此前 Xbox 剥离四家工作室、3200 人裁员之后，Xbox 第一方版图仍在剧烈收缩

— 来源：[机核](https://www.gcores.com/articles/216874)

### 4. 曝《GTA6》进入高强度赶工阶段，员工周工时超 80 小时；前制作人解释 PC 版推迟非盗版原因

Rockstar Games 员工公会匿名爆料称，R 星内部正进入《GTA6》收尾冲刺，多名开发人员每周工作时长最高可达 80 小时，全员超负荷工作。同日，曾参与《给他爱5》和《荒野大镖客》开发的 R 星前制作人约翰·里奇奥在播客中解释了 PC 版延迟发售的原因。

关键细节：

- 里奇奥表示 PC 版推迟并非技术瓶颈或对盗版的担忧，而是纯资源管理与战略优先级选择——"主机优先"能最大化首发窗口的营销聚焦
- Rockstar 尚未就加班报道作出官方回应
- 《GTA6》预计将在今年内发售，被视为游戏史上最重要的商业发布之一

— 来源：[游民星空（晚报）](https://www.gamersky.com/news/202607/2170470.shtml)

### 6. 育碧就《黑旗RE》提前创作者体验向中国玩家道歉，发放补偿奖励

### 8. 索尼光盘风波持续：法国官方直播封禁抗议玩家；实测数据力证实体盘核心价值

索尼宣布 2028 年终止实体光盘的争议持续发酵。法国 PlayStation 官方 Twitch 直播中，有玩家在聊天频道刷"No Disc, No Buy"口号并呼吁签署请愿书，旋即被管理员封禁——被外界解读为索尼"连讨论都不让讨论"。目前请愿书签名已突破 20 万。与此同时，外媒 DoesItPlay 发布大规模实测为中国玩家"捍卫实体"的呼声提供了有力数据支撑。

关键细节：
- DoesItPlay 抽样测试了 778 张 PS5 游戏光盘，结果显示 93%（723 款）游戏无需联网验证、无需补丁即可完整离线游玩；仅 4% 被网络锁限制
- 对 1200 余款 PS4 游戏的对比测试得出相似结论：92% 支持纯离线游玩
- 数据直观证明：实体盘支持永久收藏、租借、二手转卖，拥有完整所有权；数字版受平台规则限制，随时可能被下架收回
- 索尼官方目前未就封禁玩家一事作出回应；社区普遍认为"索尼铁了心不回头"

— 来源：[游民星空（晚间报）](https://www.gamersky.com/news/202607/2170470.shtml) | [游民星空（捍卫实体价值）](https://www.gamersky.com/news/202607/2170363.shtml)

## 独立游戏与开发

### 12. IOI 关闭土耳其工作室，重新获得《Project Fantasy》完整版权

《杀手》系列开发商 IO Interactive 宣布关闭其土耳其工作室，同时确认已重新获得奇幻 RPG 项目《Project Fantasy》的完整版权。该项目此前涉及与外部合作伙伴的版权纠纷，IOI 通过此次整合获得了对该 IP 的完全控制。

关键细节：
- 土耳其工作室主要承担外包和辅助开发职能，关闭不影响哥本哈根和巴塞罗那主力团队
- 《Project Fantasy》是 IOI 摆脱"杀手专业户"标签的关键一步，定位为大型奇幻世界观原创 IP
- IOI 目前仍以《杀手》系列的持续运营为核心业务

— 来源：[机核](https://www.gcores.com/articles/216871)
