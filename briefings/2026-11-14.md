### 3. 🔥 "从模型权重里读出 GPU 型号"：Unemployment Labs 取证报告称 DeepSeek、月之暗面、MiniMax、蚂蚁的六款新模型带 NVIDIA Blackwell 指纹——DeepSeek-V4 系列、Kimi K3/K3.1-Pro、MiniMax-M3、蚂蚁 Ling-3.1-flash 的初始化数值模式匹配 B200/B300/GB200；估算五次训练共用约 1.2 万张 Blackwell、仅最终训练轮就值 5 亿+ 美元（HN 351 分、145 条评论）

Unemployment Labs（Will DePue，11/12）实读：方法是从公开发布的模型权重里恢复**初始值痕迹**，再搜索能复现这些数值的硬件配置与初始化配置——不同 GPU 的处理器核心数（SM 数）会在权重里留下可检索的指纹。核心发现：四家中国实验室 2026 年 4 月以来发布的六款模型（DeepSeek-V4-Flash/V4-Pro、Kimi K3/K3.1-Pro、MiniMax-M3、蚂蚁 Ling-3.1-flash）匹配 Blackwell 系列（B200/B300 为 148 SM，GB200/GB300 为 152 SM），而同公司更早的模型一致匹配上一代 Hopper；对 DeepSeek-V4-Flash 与 Kimi K3，作者还在物理 Blackwell 芯片上确认了匹配。方法自证：24 款开发者公开过训练硬件的模型，该方法全部读对（含 NVIDIA 自家 Nemotron-3 Ultra 的 GB200 披露）；最强证据达 1,385σ（偶然匹配上限约 8σ）。规模估算：五次最终训练轮合计约 12,000 张 Blackwell（Kimi K3 约 4,500 张、DeepSeek-V4-Pro 约 3,000 张，约合 11,500/7,500 张 H100），总价值超 5 亿美元；"实验室在受管制 GPU 上的总支出很可能以十亿计"。并非全员转向：Qwen、GLM、腾讯、小米、阶跃的新模型仍读作 Hopper；美团的 LongCat-2.0 自称全跑自研 ASIC 超级pod、无 NVIDIA 指纹。作者的诚实边界也写在正文里：指纹证明的是"权重在 Blackwell 上初始化"，"支持但不证明"训练也在 Blackwell 上完成；新加坡等境外数据中心是未被排除的合法解释之一。

**关键细节：**
- 时间线被逐家读出：DeepSeek 从 V4（2026/4）起、月之暗面从 K3（2026/7）起、MiniMax 从 M3（2026/6）起、蚂蚁从 Ling-3.1（2026/10）起切到 Blackwell——Kimi K2.7-Code 是过渡态（Hopper 主体 + 一小块 B200 匹配）；K3.1-Pro 与 K3 同种子、可能是 K3 的延续后训练

### 4. Edge0-145B："全球首个开源 145B 端侧模型"号称在笔记本上跑出 1,100+ tokens/s prefill、80+ tokens/s decode、峰值内存 29GB——架构上每 64 个专家共享大矩阵、145B 参数中每步仅约 10B 参与计算；HN 社区第一反应是两极："open weights 不等于 open source"与"若第三方复测成立则非常惊人"（HN 331 分、100 条评论）

### 7. Brave Search API 接入 x402 协议：AI agent 用 USDC 按查询实时付钱，无需账户与 API key——"agentic payments"第一次被主流搜索引擎 API 做成默认通道；HN 评论："这是我听说过的最不蠢的区块链用法"（HN 254 分、168 条评论）
