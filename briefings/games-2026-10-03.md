### 6. 暴雪为《魔兽世界：Forever》补上"Kyle 失踪了！"任务：2007 年许愿基金会的传奇任务重返艾泽拉斯

### 9. 《天国：拯救2》老板盼 GTA 6 抬高游戏定价："早该涨了，这是行业活下去的必要条件"

Warhorse Studios 联合创始人 **Martin Klima** 近日接受 PC Gamer 采访，直言行业三大难题：开发成本暴涨、固定购买新游戏的受众已见顶、数字化商店消灭了零售中间商——"**我们摧毁了零售业，拿走了他们所有的钱。**"在不塞满微交易的前提下，"**最后能做的就是提高单价。这会大有帮助，但所有人都怕得要死。现在，希望 GTA 能蹚出这条路，让我们敢涨价。**"他称涨价"早该发生，也是这门生意活下去的必要条件"，而 Rockstar 与 Take-Two 是少数"付得起、也敢"率先抬价的公司。

### 14. 卡普空开源 REDox：下一代引擎 REX 的核心组件，高性能 .NET 结构化数据引擎

卡普空在 GitHub 开源 **REDox**——一个"高性能、基于 token 的结构化数据引擎（序列化/反序列化）"，官方定位为其**下一代游戏引擎 REX 的核心技术组件**之一，仓库归属于卡普空技术部门的开源组织 CAPCOM-TD-OSS。对引擎开发者而言，序列化性能直接影响关卡与资产流的加载速度，大厂把引擎基础设施开源在业内仍属少见动作。

这延续了大厂引擎技术开源的趋势（此前的 id Tech 部件、EA 的部分工具链等）。HN 社区已有讨论，关注点集中在 token 化设计与传统二进制序列化的性能取舍。
