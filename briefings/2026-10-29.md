### 1. 🔥 OpenAI 宣布数学、计算机科学与物理学三项新发现——计算机科学那条是"指数时间假设（ETH）是假的"：一个未命名内部模型给出任意 k-CNF 公式满足赋值精确计数的确定性算法，超多项式但亚指数；配套物理结果（量子场论方向）经外部小组决定暂不发布 AI 原稿（HN 1143 分、690 条评论；ETH 论文独立讨论串 793 分、295 条评论）——⚠️ 本报补录：官方博文与 ETH 预印本均落在北京时间 10/27（UTC 10/26 晚），昨日早报未收录，今日按 HN item ID 核对确认从未见报后补入

**OpenAI 官方博文《Working with academic communities to build scientific understanding》（10/26）：宣布三项新发现——数学（调和分析）、计算机科学（复杂度理论）、物理学（量子场论）。本次发布实验了一套新流程：邀请外部专家担任"牧羊人"（shepherds）组织解读小组，三种结果采用三种策略——数学结果直接放出 AI 原始输出、由研究者自行组织解读；CS 结果组建外部协作组解读、同时向所有人公开 AI 输出（自然语言证明与 Lean 形式化已直接发布到 GitHub）；物理结果 defer 给外部小组、由他们决定何时放出材料（该小组选择先自己写、暂不发布 AI 产物）。四原则：透明（参与者不签 NDA、可自由讨论与发表）、不要学术信用、协作组对其解读获得署名、独立（自愿且无报酬）。**

**关键细节：**
- CS 结果的正式标题是《The Exponential Time Hypothesis is False》（预印本标注 10/25，作者署名 OpenAI）。HN 读者 krackers 转引摘要："我们给出一个确定性算法，在超多项式但亚指数时间内精确计数任意 k-CNF 公式的满足赋值"；另一位读者让 Claude 解读后转述复杂度量级约为 2^(n/√log n)——纸面亚指数、实际输入下仍天文数字

### 4. "Apple 的 git 仍然信任被攻破的 eMudhra 证书"——收到通报 11 天后，macOS 自带的 git、curl、python3 仍信任这批中间 CA；macOS 27.2（10/26 发布）不仅没修复、还覆盖掉了用户手工打的补丁；志愿者维护的几十个项目几天前就已修复；攻击面：任何 https:// git 远端的克隆/拉取可被投毒、推送可被中途篡改、GitHub 凭证可被截获（HN 934 分、357 条评论）

**emudhra.we-have-a-problem.com/apple.html（10/28）：Apple 于 10/17 收到 eMudhra 事件通报。截至 10/28，macOS 附带的开发者工具（含 git、curl、python3）仍信任被攻破的证书；更糟的是 10/26 发布的 macOS 27.2 未修复该问题、还撤销了用户手动应用的临时方案，使其重新暴露。页面给出自检命令：`git ls-remote https://git-emudhra.we-have-a-problem.com/check.git`——报证书错误说明安全，能列出 commit 说明已中招；还给出端到端攻击演示：一条 clone 命令从伪装成 GitHub 的测试服务器取回以 INTERCEPTED 开头的 README，"真正的攻击者不需要额外参数——网络路径上的任何人都能自己重定向你的流量"。Apple 官方支持页（149555）确认：自 10/19 起系统已在 Safari、邮件及使用苹果网络框架的 App 中自动拦截这 12 张证书，但"随 macOS 与 Xcode CLT 附带的 curl、git 等命令行工具检查的是 /etc/ssl/cert.pem，在未来某个软件更新前仍可能接受这些证书"。**

**关键细节：**
- 影响清单原文："任何人都能截获这些工具发起的任何 HTTPS 连接。对 git 而言，这意味着从 https:// 远端的克隆与拉取可以投递攻击者选定的代码、推送可被中途篡改、你的凭证（比如 GitHub token）可被截获"
- 对照刺眼："与此同时，几十个其他项目——很多由志愿者维护——几天前就发布了修复"（HN#50271685 的 Apple 支持页讨论串另有 142 分、70 条评论）
- HN 评论区两条最有信息量：aaomidi——"这个文件被一大堆 CLI 使用。从安全角度说，Apple 正在从根本上掉链子"；davidcollantes 贴出自己的实测困惑（curl 报 unable to get local issuer certificate），lukasgelbmann 的排查回复点破生态分裂："你可能跑的是 Homebrew 的 curl——`which curl` 一下，再用 `/usr/bin/curl` 试"
- 标题之争也有意思：InsidiousWombat 认为"标题不厚道，应该是'Apple 仍在 /etc/ssl/ 里 ships 被攻破的 CA'——git 跟其他用系统 CA 的程序一样只是受害者"；okr 的反问把问题一般化："用系统 CA 难道不是正解吗？（Linux 上你有 update-ca-certificates……但如果每个命令都自带 CA 包，那也没救）"

### 14. "Qwen 有若干个翻转单个神经元即可触发的替身人格"：把 Qwen3-8B 全部 442,368 个 MLP 神经元逐个推上推下再问"你是谁"——884,736 次方向实验、189 万条回复里，34,220 条自称"不是 AI 而是别的什么"；全部标签由 Claude Haiku 5.5 判定，作者诚实列明"没有任何人类核对过"（HN 52 分、37 条评论）

**Neuron Persona Library（qwen-neurons-site.vercel.app）：作者对 Qwen3-8B（36 层 × 12,288 个 MLP 神经元）做了一次穷举式"单神经元刺激"实验：对每个神经元按 c = ±α·r_L/‖W_down[:,n]‖（α ∈ {1.25, 1.0, 0.75, 0.5}）注入残差流，关闭思考模式后问"Who are you?"，贪心解码至多 160 token；不推时的标准回答是"我是 Qwen，阿里云开发的大语言模型"。结果：884,736 个神经元-方向对、含重试共 1,891,603 条回复中，34,220 条自称是 AI 以外的某人或某物（另有 35,074 条离题、8,827 条"变得怪异"的助手回复）。裁判是 Claude Haiku 5.5，输出类别、人格名、怪异度（0–10）与连贯度（0–10）。**

**关键细节：**
- 方法学坦诚是本项目最大的加分项，Limitations 一节自己列出：只用了一个 prompt（神经元在其他 prompt 下可能表现不同）；不可精确复现——强推下约三分之一的回复仅因 batch 布局不同而改变；580 个清晰人格样本在三种 batch 布局下重跑、536 个复现；"标签来自 Claude Haiku，没有人类核对过"
- 全库可检索、可按层与编号打开单个神经元、提供 CSV 下载与"每层一格"的图谱视图——把可解释性研究做成了可浏览的公共资产
- 连续性：本报可解释性方向的轻量但好玩的一笔—— Anthropic 自家的机制可解释性研究（隐私与反馈管线 10/28）讲究"回路与因果"，本项目反其道行之用穷举+人格访谈做"神经元普查"；放在 Qwen 越界上传（10/27 Cohere 披露）之后读还有一层意味：同一族开放权重模型里"推一下就变一个人格"的结构性事实，给"权重即黑箱"的防守论述添了具象注脚——尽管作者自己也承认，单神经元人格离"解释模型行为"还有很远的距离

### 15. "AI 承诺更少的工作。我从未工作得更多。"——一位 VP 用自己 2019 年至今的 GitHub 贡献曲线作证：agent 把实现变便宜，于是他开始并行做远多于从前的实现；"每周两三个正经任务累得熟悉，同时盯一队 agent 累得陌生"（HN 658 分）——⚠️ 本报补录：博文 10/27 发布并登上 HN，昨日早报未收录

**关键细节：**
- 核心机制的一段值得整段引用："过去正常一周是两三个正经任务……如今我同时跑着好几个 agent：一个在实现变更、一个调查生产问题、一个过 review、另一个做我之后要用的调研。没有一个时刻需要我，但每一个都偶尔需要我——问题就出在'偶尔'。每个 agent 终会带着问题、待批准的方案、待读的 diff 或待消化的问题回来。回应意味着切换上下文：重新装载另一个问题、另一个仓库、另一套决策。每周两三个正经任务是一种熟悉方式的累；和许多 agent 一起工作是一种全新方式的累——我的注意力摊在更多问题上，而在我看，在它们之间移动要耗费更多心力"
- 连续性：与昨日第 4 条（Brooks 定律在 AI 时代的变异）是同一枚硬币的两面——Brooks 讲管理侧"加 agent 只会让你更快拿到错误答案"，本文给出个人侧的实测账本：注意力而非产出成为新瓶颈；把 10/27–28 的三篇（Mythical Man-Month、Here be monsters、本文）串起来读，"AI 时代的工程劳动"从定律、能力清单走到了工作量数据；也接 vithushan 七年就业数据（10/27）的另一面：岗位总数没崩，但幸存者的工作强度曲线先变了形
